# Worst Superpower — Phone Locator, Already Holding It

make.fun entry for [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe): invent the most useless superpower in one line of 140 characters.

> I always know exactly where my phone is, but only when I'm holding it.

`main.py` (Python 3, stdlib only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
